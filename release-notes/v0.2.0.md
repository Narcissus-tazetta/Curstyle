Try themes before you apply them, and mix your own.

**New**
- **Try it** lets you test a theme on text, links, buttons, and a map sample without changing your system cursor.
- Compare up to four themes side by side, each with its own size control and a light or dark background.
- Replace a single cursor with one from another theme or a GIF / PNG, with a before-and-after preview. Add cursor roles a theme is missing.
- **Undo** (⌘Z) reverts saved edits one at a time, and the history survives restarts. Edits made before this version can't be undone.

**Improved**
- Lower CPU use while the mouse is moving with the overlay backend.
- Size fields for GIF / PNG replacements no longer save values outside 8–128 pt.

Apple Silicon only, tested on macOS 27.2. Curstyle is not notarized: on first launch, choose **Open Anyway** in System Settings → Privacy & Security.
