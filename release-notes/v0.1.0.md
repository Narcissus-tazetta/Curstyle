First public release of Curstyle, a macOS cursor theme changer.

**Get themes**
- Import Windows cursor themes (`.cur` / `.ani`), Mousecape `.cape` files, and GIFs.
- Long animations are resampled to 24 frames automatically.

**Make them yours**
- Preview every cursor, animated, in light and dark mode.
- Edit hotspots and animation speed, replace any cursor with a GIF or PNG, and scale the whole theme from 0.1x to 5x.

**Use them**
- Apply a theme, or go back to the macOS defaults, from the app or the menu bar.
- Your theme is reapplied after login, restart, wake, and pointer setting changes.
- If a theme does not show up, built-in diagnostics can export a report.

**Also**
- Updates arrive in-app through Sparkle.
- English and Japanese.

Apple Silicon only, tested on macOS 27.2. Curstyle is not notarized: on first launch, choose **Open Anyway** in System Settings → Privacy & Security.
